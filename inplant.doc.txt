# InPlant Dashboard - Comprehensive Design Document

## 1. Executive Summary

### Purpose
Create a real-time visibility dashboard for in-plant vehicle movement tracking, enabling clients to monitor shipments from external parking through gate-out, with historical data access capabilities.

### Target Users
- Plant managers
- Logistics coordinators
- Client stakeholders monitoring their shipments
- Operations teams

### Screen Constraints
- Primary resolution: 1300px × 720px
- Must be fully functional without scrolling for active monitoring
- Responsive design for larger screens

---

## 2. Information Architecture

### 2.1 Primary User Goals
1. **Monitor Active Shipments** - See current status of all vehicles in plant
2. **Identify Bottlenecks** - Spot delays and congestion points quickly
3. **Track Individual Vehicles** - Find specific shipment details
4. **Historical Analysis** - Review past operations for patterns
5. **Take Action** - Export data, generate reports, escalate issues

### 2.2 Data Hierarchy
```
Level 1: Plant-wide Metrics (Top Priority - Always Visible)
├── Total active vehicles
├── Average processing time
├── Current delays/alerts
└── Stage-wise distribution

Level 2: Stage Flow Visualization (High Priority - Always Visible)
├── Vehicle count at each stage
├── Stage health indicators
└── Flow rate/throughput

Level 3: Vehicle List (Primary Content)
├── Real-time vehicle status
├── Key identifiers
├── Current location
└── Time metrics

Level 4: Individual Vehicle Details (On-Demand)
├── Complete journey timeline
├── Documents and weights
├── Driver/transporter info
└── Delay reasons
```

## 8. Interaction Patterns

### 8.1 Search Functionality

**Vehicle/Driver Search:**
- Real-time search as user types (debounced 300ms)
- Search across: Vehicle number, driver name, shipment ID
- Highlights matching results in table
- Clear search button (×)
- Recent searches dropdown (last 5)

**Keyboard Shortcuts:**
- `Ctrl/Cmd + K`: Focus search
- `Esc`: Clear search and close modals
- `↑↓`: Navigate table rows
- `Enter`: Open detail panel for selected row

### 8.2 Filtering

**Quick Filters (Chip Style):**
- Single select: [All] [Active] [Completed] [On Hold]
- Status: [Delayed] [At Risk] [On Track]
- Time: [Last Hour] [Last 4h] [Today] [Yesterday]
- Active filter has blue background, count badge

**Advanced Filters (Collapse Panel):**
```
┌─────────────────────────────────────────┐
│ Advanced Filters                    [×] │
├─────────────────────────────────────────┤
│ Stage:         [All Stages ▼]           │
│ Shipper:       [All Shippers ▼]         │
│ Carrier:       [All Carriers ▼]         │
│ Date Range:    [From] [To]              │
│ Duration:      [Min] - [Max] minutes    │
│                                          │
│           [Reset] [Apply Filters]       │
└─────────────────────────────────────────┘
```

### 8.3 Date Range Selection

**Preset Options:**
- Today (default for active view)
- Yesterday
- Last 7 days
- Last 30 days
- Custom Range

**Custom Range Picker:**
- Calendar popup
- Quick select: Start of day, End of day
- Max range: 90 days for performance

### 8.4 Refresh Behavior

**Auto-refresh:**
- Default: 30 seconds
- Options: 15s, 30s, 60s, Off
- Pause on detail panel open
- Visual countdown indicator
- "New data available" notification with manual refresh option

**Manual Refresh:**
- Button click or `Ctrl/Cmd + R`
- Loading spinner on button
- Brief flash animation on updated rows
- Toast notification: "Updated 5 vehicles"

### 8.5 Sorting

**Sortable Columns:**
- Vehicle Number (alphanumeric)
- Current Stage (by stage order)
- Entry Time (chronological)
- Duration (numeric)

**Sort Indicator:**
- ↑ Ascending
- ↓ Descending
- Default: Entry Time (newest first)

### 8.6 Export Functionality

**Export Options:**
```
[Export ▼]
  ├─ Current View (CSV)
  ├─ Current View (PDF)
  ├─ All Active Vehicles (Excel)
  └─ Detailed Report (PDF)
```

**Export Configuration:**
- Includes applied filters
- Timestamp in filename
- Logo and plant name in header
- Page numbers for PDF

## 11. Performance Optimization

### 11.1 Front-end Optimization

**Virtual Scrolling:**
- Implement for tables with >100 rows
- Render only visible rows + buffer (5 rows)
- Maintain scroll position on refresh

**Data Management:**
- Cache API responses (5 minutes)
- Implement optimistic updates
- WebSocket for real-time updates (future enhancement)
- Local storage for user preferences

**Bundle Optimization:**
- Code splitting by route
- Lazy load detail panel
- Optimize images and icons
- Tree-shake unused libraries

### 11.2 API Optimization

**Pagination:**
- Default: 20 items per page
- Max: 100 items per page
- Cursor-based for large datasets

**Caching Headers:**
- Live data: no-cache
- Historical data: 5 minutes
- Static assets: 1 year

**Request Optimization:**
- Debounce search: 300ms
- Throttle refresh: Min 10s
- Batch filter requests

### 11.3 Rendering Performance

**Target Metrics:**
- First Contentful Paint: < 1.5s
- Time to Interactive: < 3s
- Auto-refresh impact: < 100ms
- Table sort/filter: < 200ms

## 12. Accessibility Standards

### 12.1 WCAG 2.1 AA Compliance

**Color Contrast:**
- Text: Minimum 4.5:1 ratio
- Large text: Minimum 3:1 ratio
- Status colors tested with color-blind simulators
- Never rely on color alone (use icons + text)

**Keyboard Navigation:**
- All interactive elements tabbable
- Visible focus indicators (2px blue outline)
- Skip to main content link
- Escape key closes modals/panels
- Arrow keys navigate table

**Screen Reader Support:**
- Semantic HTML (table, nav, main, aside)
- ARIA labels for icons and status
- ARIA live regions for updates
- Alt text for all images
- Table headers properly associated

- JWT token-based auth
- Token refresh mechanism
- Session timeout: 8 hours

**Authorization:**
- Role-based access control (RBAC)
- Plant-level data isolation
- Client-specific data filtering
- Audit logs for sensitive actions

**XSS Prevention:**
- Sanitize all user inputs
- Content Security Policy headers
- Escape HTML in dynamic content

**Data Protection:**
- No sensitive data in localStorage
- Secure cookie settings
